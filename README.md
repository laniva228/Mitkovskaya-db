Фитнес-клуб



Данный проект представляет базу данных для фитнес-клуба. Пользователями системы являются администраторы, тренеры и клиенты фитнес-клуба

Система предназначена для хранения информации о тренерах, абонементах, упражнениях, тренировках и посещениях

Администратор может использовать данные для контроля абонементов и посещаемости клиентов

Тренеры могут получать информацию о тренировках и расписании. Данные также можно использовать для анализа популярности тренировок и загрузки фитнес-клуба

Я выбрала эту тему, потому что она понятна мне и позволяет создать достаточно большую базу данных
